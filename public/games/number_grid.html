📖 How to Play Number Grid — Rules, Tips & Strategy

Game Objective

Number Grid is an analytical arithmetic deduction puzzle that challenges your mental math and matrix reasoning skills. You are presented with a square grid (3x3 on Easy, 4x4 on Medium, and 5x5 on Hard) where individual empty cells must be populated with integers such that the sum of each horizontal row exactly matches its row target indicator (→) and the sum of each vertical column exactly matches its column target indicator (↓).

Grid Rules & Integer Constraints

In standard mode, each cell accepts positive integers within a defined range depending on difficulty. Some cells are pre-revealed as numerical clues to establish starting anchors. When you input a number into an editable cell, you must consider both its horizontal row sum and its intersecting vertical column sum simultaneously.

Solving Techniques & Row/Column Intersections

Begin by scanning for rows or columns that have only a single missing value. For example, if a 3-cell row has targets of 15, and two cells already contain 4 and 8, the remaining cell must unequivocally be 3 (15 - 12 = 3). Once filled, check the vertical column that intersects this newly entered number to narrow down options for adjacent rows. Using process of elimination prevents trial-and-error mistakes and earns higher speed multipliers.

Single Unified Hint System & Scoring

Need assistance on a difficult puzzle? The central arena hint button allows you to spend coins to automatically uncover the exact solution for any unsolved cell. Hint costs escalate with each usage in a session (10, 20, 30 coins), preserving high scores for tactical players. Scores are awarded based on matrix dimensions and speed bonuses, contributing toward your daily streak count and global World Wars ranking.
